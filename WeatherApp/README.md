# 🌤️ Weather App

A responsive weather forecast application built as part of **The Odin Project's JavaScript curriculum**. The app uses the **Visual Crossing Weather API** to retrieve and display weather information for searched locations.

## Features

* 🔍 Search weather by location
* 🌡️ Toggle between Celsius and Fahrenheit
* 📅 Display a 5-day forecast
* 💨 View wind speed and humidity
* 🌤️ Weather condition icons
* 🎨 Dynamic background based on weather conditions
* ⏳ Loading state
* ❌ Error handling
* 📱 Responsive design

## Technologies

* HTML5
* CSS3
* JavaScript (ES6+)
* Webpack
* Visual Crossing Weather API

## Getting Started

Clone the repository and install the dependencies:

```bash
git clone <your-repository-url>
cd weather-app
npm install
```

Create a `.env` file in the project root:

```env
WEATHER_API_KEY=your_api_key_here
```

Start the development server:

```bash
npm start
```
